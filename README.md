# 天命 · 崇祯

**v0.1.0-alpha.1 · 首个公开测试版**

扮演崇祯，从 1628 年接手明末的财政、军务与官场。与群臣和各署主官议事，用自己的话任命人物、安排预算、设立机构、推动改革与探索海路，在历史约束与架空发展之间改变这局国家的走向。

这是本机运行的中文网页策略游戏。浏览器负责界面，本地 Node.js 服务负责规则、存档和 AI 请求。DeepSeek 或兼容的聊天接口可参与议事与政令拟定；不填写密钥也能体验预设施政与月度结算。

## 下载试玩

前往 [Releases](https://github.com/DXF-roadman/chongzhen-simulator/releases) 下载 **chongzhen-simulator-v0.1.0-alpha.1-windows-x64.zip**。

1. 解压整个文件夹到一个可写目录，不要直接在压缩包里启动。
2. 双击 **启动游戏.cmd**。Windows 试玩包附带官方 Node.js 运行时，不必另行安装。
3. 浏览器自动打开 http://127.0.0.1:17628/ ，开始新局。
4. 退出服务时双击 **停止游戏.cmd**。关闭网页后，本地服务仍会运行。

如果下载的是 GitHub 自动生成的 Source code 压缩包，请先安装 Node.js 20 或更新版本，建议使用 Node.js 24 LTS，然后双击启动脚本，或在项目目录执行：

```sh
node server.mjs
```

无需 npm install，没有第三方应用运行依赖。游戏主要在 Windows 上验证；其他平台可运行本地服务，AI 密钥可通过 DEEPSEEK_API_KEY 环境变量提供，界面内保存密钥的功能依赖 Windows。

## 先玩什么

- **山河总览**：查看地方局势、实控、军情和已知航路；探索到的新地点会出现在同一张主舆图上。
- **御前议事**：与群臣、人物或指定机构持续交谈。询问先商议，明确下旨后核验办理结果。可删除、修改或重答未执行对话；已执行的政令记录保留。
- **朝廷机构**：查看现任主官、属员推荐、在办事项、预算与近期成果，也可进入该署独立对话。
- **军务**：管理部队、统帅、装备、训练、补给及出征；新建部队与给旧军补装分别办理。
- **钱粮国策**：核对收入、俸禄、常设经费和月结账簿。每月施政不限次数，以钱粮、工期和实际条件约束。
- **规划备忘与国史档案**：保存短中长期目标，到期提醒复议；岁末生成年度总结。

例如可以先问：“户部，当前钱粮最紧张的地方在哪里？”再决定是否采纳建议。办理前可以自行议定预算，也可以免费将待批奏报留中。正常月份可以没有新急报，奏报按局势触发，发展续报依据新增成果生成。

## 接入 AI

打开右上角 **AI 设置**，填入自己的 API Key，核对供应商提供的 HTTPS 接口地址与模型名称，再启用并测试。默认使用 DeepSeek 的接口地址。兼容服务仍须支持本作使用的聊天与结构化输出格式，不保证所有供应商均可兼容。

密钥由本机 Windows 账户通过 DPAPI 加密保存在 data/ai-config.json，不包含在游戏导出存档中。本项目和发行包均不附带共享密钥。AI 请求由填写的供应商处理，并按该供应商规则计费；会发送当前议事对象可知的游戏状态及相关对话。普通本地结算不会调用 AI。

AI 的建议须转成规则引擎认可的事项才会执行。模型不能只靠一段叙述直接改写任意程序机制；接口失败时会提示并保留输入。

## 存档与更新

当前局势保存在 data/autosave.json，另有三个手动存档槽，可在游戏中导入或导出 JSON。公开包从全新局面开始，不含作者个人进度、对话或设置。

更新前停止游戏并备份整个 data 文件夹。新版本解压到新目录后，确认版本兼容，再复制旧 data 继续游玩。更换 Windows 账户或电脑后，需重新填写 AI 密钥。多个浏览器窗口共享同一个本地存档。

## 测试版边界

这是早期测试版，复杂自由政令、长局与跨系统组合仍需玩家反馈。数值、人物能力、合并地区及战略控制区是游戏抽象；海陆底图不是 1628 年政治疆界，月份也不是精确农历换算。战役是战略模拟，尚无逐城、逐师战术战斗。史实提供背景，人物结局和亡国年份不强制照搬。

本版本重点验证状态、月结、存读档与自然语言办理的一致性。详见 [版本说明](RELEASE_NOTES.md)。

## 反馈与开发

遇到问题请到 [Issues](https://github.com/DXF-roadman/chongzhen-simulator/issues) 提交：发生前的操作、预期结果、实际结果、版本号及可复现步骤。截图或存档可帮助排查；存档包含游戏对话，分享前请自行检查，勿附 API Key。

运行测试：

```sh
node --test test/*.test.mjs
```

engine.mjs 为规则引擎，state-store.mjs 为统一存档校验，server.mjs 为本机 HTTP 与 AI 服务，public/ 为无需构建的界面，test/ 为隔离测试。AI 自动测试使用模拟供应商，不需要真实密钥。

海陆数据使用 Natural Earth 公有领域数据，来源与处理说明见 [地图数据说明](public/world-land-LICENSE.txt)。Windows 试玩包的 Node.js 运行时授权见 runtime/LICENSE。
